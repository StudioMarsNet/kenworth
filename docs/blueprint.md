# **App Name**: KW Inventory System

## Core Features:

- Inventory Data Upload: Upload inventory data from Excel or CSV files for immediate analysis.
- Stock Visualization: Display current stock levels separately for Bisonte SLP and Exclusa SLP.
- Low-Movement Identification: Identify and highlight low-movement items that inflate inventory value.
- Commission Projection: Calculate and project the sales percentage of total inventory to estimate potential commissions based on KPIs.
- Requisition & Transfer Tracking: Record and track the status of parts requisitions and inter-warehouse transfers.
- Report Generation: Generate reports showing the potential impact of inventory reduction on commission.
- Trend Forecasting: Based on a historical view of previous sales performance, determine the effect that changes in inventory is likely to have on commisions. The LLM tool analyzes trends to identify products that are likely to stagnate in inventory and/or be popular, helping managers plan which items to transfer and how many of each will optimize commission.

## Style Guidelines:

- Primary color: Deep Kenworth Red (#B71C1C), conveying strength and reliability, reflecting the Kenworth brand.
- Background color: Light gray (#F5F5F5), offering a clean, professional backdrop that enhances data visibility.
- Accent color: Muted gold (#FFD700) highlighting critical data points and CTAs with a touch of prestige and value.
- Body font: 'PT Sans', a humanist sans-serif, ensures readability and combines a modern with a warm, accessible feel. Headlines: 'Space Grotesk' (sans-serif), creating a contemporary, tech-focused look for headers; if longer text is anticipated, use 'PT Sans' for body
- Use clear, functional icons to represent inventory status, requisitions, and transfers for quick visual understanding.
- Design a clean, data-centric layout with clear sections for inventory, reports, and tracking, ensuring easy navigation.
- Employ subtle transitions and animations to indicate data loading and updates, providing a smooth and responsive user experience.
